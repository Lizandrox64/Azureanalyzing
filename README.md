## 🎯 ¿Qué hace este dashboard?

Este dashboard convierte tus archivos CSV de autenticación de Azure Active Directory en un **panel de control interactivo** que te permite:

- 🔐 **Analizar métodos de autenticación** usados en tu tenant
- 📊 **Visualizar tasas de éxito/fallo** por método y período
- ⏰ **Detectar patrones temporales** de actividad
- 🛡️ **Monitorear adopción de MFA** (Multi-Factor Authentication)
- ❌ **Identificar errores comunes** y sus causas
- 👥 **Entender comportamiento de usuarios** y sesiones
